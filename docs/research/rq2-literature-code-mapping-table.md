# RQ2 先行研究→コード対応表（論文・付表用）

更新日: 2026-09-22  
対象: RQ2「相手に応じた英語対話行動の類型化」

## 1. 位置づけ

本表は、RQ2コードブックv1の各コードについて、どの先行研究・理論を根拠にし、どの部分を本研究用に修正・新設したかを明示するためのものである。

コード体系全体は、既存のL2相互行為能力研究、interactive listening、Small Talk、AI／音声対話システム研究、recipient design／grounding研究を演繹的出発点とし、今後の開発用120系列によって帰納的に精緻化する。

## 3. 境界判断で特に重要な対応

### B0 と B3

Lam (2018) のcontingencyを踏まえ、単に前ターンの質問に答えただけではB3としない。

- AI: What sport do you like?
- Child: I like soccer.

参照基盤は原則B0、対話機能はRES。

一方、

- AI: I have a dog.
- Child: What is your dog's name?

では、AIが新たに提示した内容を児童が次発話に取り込んでいるためB3、機能はTOP。

### Q と TOP

疑問文という形式では判定しない。

- 一般的・準備的な新規質問 → Q
- 相手の直前内容に依存した追加質問 → TOP

### ACK と TOP

- Oh. / I see. / Really? など、主として受け止め・傾聴を示す → ACK
- 受け止めに加え、具体的内容を関連付けて話題を前進させる → TOP

### COMP と REP

- 理解できるか、意味が何かを確認・要求する → COMP
- 問題を解消するため自分の発話を修正・言い換える → REP

## 4. そのまま採用しなかった研究枠組み

- **Storch (2002)**: 高引用であるが、ペア全体をequality×mutualityで類型化するため分析単位が異なる。
- **turn-taking timing / overlap**: 押して話すUIがターン境界を強く規定するため、児童の自然なターン管理として扱いにくい。
- **prosody**: 音響分析用データを研究ログに保持していない。
- **ISO 24617-2の詳細タグ体系**: 小学生の短時間対話に対して過剰分類になるため、基本機能の理論確認に限定。
- **Su & Chen (2026)の拒否ロールプレイ特有カテゴリー**: 本研究の自由度の高いAI対話にそのまま適用しない。

## 5. 方法節に使用できる記述案

> RQ2の類型化では、既存のL2相互行為能力、interactive listening、Small Talk、AI対話・grounding研究を理論的出発点として候補コードを設定した。特に、話題展開および聞き手としての反応についてはGalaczi（2014）、前話者の発話内容に依存した応答についてはLam（2018, 2021）、国内小学校英語における反応および関連質問については山口・巽（2020）、山口・吉澤（2023）、小林・古屋・中川（2021）を参照した。また、音声対話システムおよび生成AIとの対話に既存の相互行為能力枠組みを適用・修正した研究（Gokturk & Chukharev, 2024; Su & Chen, 2026等）を参考にした。その上で、本研究では、相手情報が段階的に具体化する研究デザインを捉えるため、発話が何を手掛かりに構成されたかを示す「参照基盤」を独自に操作化した。候補コードは開発用標本を用いて帰納的に精緻化した後に確定し、確定に使用していない標本を用いて独立二重コードを行う。
